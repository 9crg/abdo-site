# abdo — art website

- `index.html` is the design. You never need to touch it.
- `content/site.json` holds all the words and the list of works.
- `media/` holds the images.

Edit everything at https://app.pagescms.org (sign in with GitHub, open this repository, click "My website").
Tips: export images as JPG around 2000 px wide so the site stays fast. Drag works up or down in the list to reorder them.
